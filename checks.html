What PriceKeeper has to pass

Every change to this app is tested by TestSprite before it can go live. This page lists every test, every bug the tests found, and every result, with a link to the run behind each one. It is built from the GitHub and TestSprite records, not typed by hand.

How the checks run

  1. Every pull request gets its own preview copy of the app. TestSprite's GitHub App runs all the browser tests on it, and GitHub will not merge the change until they pass.
  2. The server tests talk straight to the database, the way an attacker would. On a pull request they run against a local copy of the database with that change's rules. After a merge, TestSprite runs them against the real database.
  3. When a run fails, a comment appears on the pull request saying which test failed, the step it stopped on, and what TestSprite saw there.
  4. Every morning a few tests run on the live site, including the two that cut the internet. If one fails, an issue opens on GitHub by itself.
  5. The money maths has 64 unit tests of its own, run on every push.
